## Esquema de Niveles de Seguridad

| Nivel | Definición |
| :--- | :--- |
| **1. Uso público** | Se puede conocer libremente. Que se filtre no supone ningún riesgo para el negocio. |
| **2. Difusión limitada** | Circula dentro de la empresa. Si se filtrara, el daño sería pequeño. |
| **3. Confidencial** | Solo debe conocerla un grupo reducido de personas. Si se filtrara, el daño sería significativo. |
| **4. Reservada** | Solo debe conocerla su propietario directo. Si se filtrara, el perjuicio sería grave. |
| **5. Secreta** | Su revelación causaría un perjuicio excepcionalmente grave. El nivel máximo. |
